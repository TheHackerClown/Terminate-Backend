## Terminate Backend
A Multi-Player Game Server Backend, originally used for 2D map based Shooter Game Terminate.

## File Structure

index.js --> Main Multi-player Websocket Based Server

utils.js --> Functions and Classes for RAM Based Server Database.

value.js --> Special Codes used for communications.
